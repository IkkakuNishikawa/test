# 要求定義書（ドラフト）

## 1. 背景・目的
- フロントエンド（React）とバックエンド（Node.js/Express）を同時に体験したい上級志向の子ども向けに、実務さながらの学習体験を提供する。
- TypeScript を標準言語とし、モダンな開発フロー（Git、npm、テスト、レビュー）を安全なブラウザ環境で再現する。

## 2. ターゲットユーザー
- 小学校高学年〜高校生で、Scratch や Python などの基礎経験を持ち、より高度な開発に挑戦したい層。
- 講師・メンター（塾、学校、オンラインコミュニティ）およびシステム管理者。

## 3. スコープ
- Web ブラウザで完結する統合学習環境（Web IDE、プレビュー、ターミナル）。
- コース／課題の配信と進捗管理、バッジ・評価機能。
- コード提出、講師レビュー、再提出ワークフロー。
- サンドボックス実行（React SPA + Node.js API）と模擬デプロイ。

## 4. 機能要件（ハイライト）
1. **アカウント管理**: 学習者／講師／管理者ロール、OAuth2.0/OIDC を使った既存 ID 連携。
2. **コース・課題管理**: レベル別カリキュラム、チュートリアル＋自由課題、開始期限・提出期限の設定。
3. **Web IDE**: ファイルツリー、複数タブエディタ、TypeScript 型補完、ESLint/Prettier 相当のチェック。
4. **プレビュー＆API 検証**: React アプリのライブプレビュー、Node.js API のリクエスト／レスポンス検証 UI。
5. **提出・レビュー**: コードスナップショット保存、差分表示、講師コメント、再提出リマインド通知。
6. **学習分析**: 進捗ダッシュボード、学習時間ログ、バッジ／ランク付与。

## 5. 非機能要件
- **可用性**: 月間稼働率 99.5% 以上。
- **性能**: IDE で編集→プレビュー反映まで 3 秒以内、課題一覧 API 500ms 以内。
- **セキュリティ**: RBAC、講師レビュー承認フロー、サンドボックス隔離、通信は全て HTTPS。
- **運用性**: APM/ログ監視、障害通知（Slack / Mail）。
- **互換性**: Chrome/Edge/Firefox 最新版、タブレット（横画面）での利用を許容。

## 6. 制約・前提
- クラウド上のコンテナ（Kubernetes もしくは類似マネージド基盤）でサンドボックスを実行。
- Node.js 20 / React 18 / TypeScript 5 系を標準バージョンとする。
- 既存の学校／塾 ID 基盤と SSO 連携するケースを想定し、学習者データの取り扱いポリシーに準拠。

## 7. 成功指標
- βリリース 3 か月で上級コース完走率 60% 以上。
- 講師レビューの平均応答時間 48 時間以内。
- 学習継続率（30 日後アクティブ） 70% 以上。

## 8. サービス機能一覧
1. **ユーザー・認証管理**: SSO/OAuth2.0、ロール管理、アカウント設定、保護者・講師招待。
2. **コンテンツ配信**: コース／課題の作成・公開・タグ付け、難易度・所要時間メタデータ設定。
3. **Web IDE + WebContainer 実行**: React/Node/TS テンプレート生成、ファイル編集、ブラウザ内 Node 実行、プレビュー共有リンク。
4. **実行確認ビュー**: フロントエンド（SPA）とバックエンド API の動作を即時プレビューする画面、レスポンスログ・リクエストヘッダ表示、マルチデバイスプレビュー。
5. **評価・提出ワークフロー**: スナップショット提出、差分表示、講師コメント、再提出リマインド、成績反映。
6. **学習分析・可視化**: 進捗ダッシュボード、学習時間/提出履歴、バッジ・ランク自動付与、CSV/JSON エクスポート。
7. **学習管理 (LMS) 機能**: カリキュラム編成、受講者グルーピング、進捗ロック/解放、出席・課題提出状況の一覧、保護者・講師向けレポート。
8. **LLM 質問サポート**: IDE からの自然言語 Q&A、コード補助、課題ヒント生成、講師による回答ラベル付けやフィルタリング、プロンプトログの監査。
9. **管理・運用機能**: システム設定、外部サービス連携（SSO、ストレージ）、ログ/監査、障害アラート。

## 9. インターフェース概要
- **フロントエンド UI**: React SPA（ダッシュボード、IDE、レビュー、設定）、WebContainer SDK と組み合わせてブラウザ内での開発体験を提供。
- **バックエンド API**: RESTful API (`/api/v1/...`) によりユーザー／コース／提出／通知などのデータ操作を提供。JWT で保護し、GraphQL 追加も検討。
- **外部接続**:
  - 認証: OIDC/OAuth プロバイダとのトークン交換。
  - 通知: SMTP/SendGrid、Slack Webhook。
  - ストレージ: S3 互換バケットでスターター Zip・提出物・ログを保管。
  - 分析: Datadog/Looker など BI 連携用のデータエクスポート API。
  - 生成 AI: LLM ベンダー API（OpenAI, Azure OpenAI, Anthropic 等）への推論リクエスト、プロンプト/レスポンスの監査ログ保存。
